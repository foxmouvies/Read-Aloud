# Development roadmap

Baseline: audit of 2026-11-25 (docs/AUDIT-2026-11-25.md). Cycle 1 authorized and in progress.

1. Cycle 1 - Reliability: fix B1 pitch/voice, B2 chunking wiring, B3 utterance watchdog, B4 popup live state, B7 icon consistency; production build script excluding tests/docs. No permission changes.
2. Cycle 2 - Extraction quality: Readability-class article extraction; multi-column PDF; fixtures for complex pages, two-column PDF, Arabic, long documents, special characters.
3. Cycle 3 - Experience: settings persistence + progress resume (storage permission, owner decision), page sentence highlighting, keyboard shortcuts, accessibility sweep.
4. Cycle 4 - Production readiness: release/versioning discipline, store submission prep (owner accounts), performance and memory benchmarks, final documentation.

Defer: OCR for scanned PDFs; neural voices beyond OS (evaluate privacy/offline tradeoff first).
